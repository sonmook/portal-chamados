# Evolução visual e funcional da Nexaltri

O projeto começou como **Portal de TI** e passou a usar a identidade **Nexaltri na v1.15.0**. Esta galeria preserva capturas reais e permite acompanhar a evolução. Todas as telas usam dados fictícios de demonstração.

As datas abaixo são registros de integração no Git, no fuso **America/Sao_Paulo**; não representam necessariamente a hora em que uma imagem foi capturada. Capturas de desenvolvimento e experimentos não significam que todas as telas estavam na Release final. A página de [Releases oficiais](https://github.com/sonmook/portal-chamados/releases), o [CHANGELOG](../CHANGELOG.md) e as notas de cada versão registram a publicação e o comportamento.

## Como registrar as próximas etapas

Use uma pasta por versão, documente commit/data/viewport e dados de demonstração, revise as telas e atualize esta linha do tempo. Preserve os bytes das capturas anteriores. Não recrie uma tela moderna e a apresente como se fosse uma captura antiga. Quando não houver imagem preservada, mantenha essa ausência explícita.

O processo de [publicação de versões](versionamento.md) vincula as Releases aos commits e às notas correspondentes.
