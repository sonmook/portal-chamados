# Prévias do relatório Excel v1.17.0

Imagens das três abas, com dados fictícios gerados em banco temporário por `scripts/prever_relatorio_excel.py`. Os autores e um atraso foram definidos somente nesse cenário de demonstração.

- `relatorio-excel-resumo.png`: indicadores e gráficos do período.
- `relatorio-excel-desempenho.png`: equipes, analistas e solicitantes.
- `relatorio-excel-resolucoes.png`: todos os ciclos do recorte, com datas, duração e SLA.

As imagens foram renderizadas a partir do arquivo Excel preenchido. O arquivo também foi aberto pelo LibreOffice Calc para verificar a interpretação das abas e gráficos. A interface e a geração em Microsoft Excel não foram automatizadas neste ambiente.

O manifesto registra os hashes das imagens e do modelo visual. Novas versões preservam estas capturas e usam outra pasta.
