# Portal de TI v1.7.0

Uma central de Administração para reunir as ferramentas de gestão e simplificar o cabeçalho.

## Novidades

- Administração substitui os links separados de usuários e equipes.
- Acessos organizados a Usuários, Equipes, Encaminhamento, Conquistas e Auditoria.
- Navegação indica a área administrativa nas telas de gestão e oferece retorno à central.
- Coleção pessoal de conquistas permanece separada das configurações administrativas.
- Acesso exclusivo de administradores validado no servidor; permissões existentes preservadas.

## Atualização

Faça backup, atualize a main após o merge, colete estáticos em produção e reinicie aplicação e processo de alertas. Sem nova migração ou dependência. Os endereços anteriores e dados permanecem disponíveis. A Auditoria reutiliza a consulta protegida existente, sem liberar edição ou exclusão.

[Funcionamento e acessos](../administracao.md).

Depois do merge e dos três checks aprovados, publique pelo workflow Publicar versão, branch main, opção atual. Preparar o código não publica a Release automaticamente.
