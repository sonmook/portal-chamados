# Nexaltri v1.16.0

Exportação das resoluções dos indicadores administrativos para CSV.

Em **Administração → Indicadores**, aplique equipe e período e use **Exportar CSV** na seção **Ciclos concluídos**. O arquivo contém todas as páginas do recorte, na mesma ordem do detalhamento, com uma linha por ciclo concluído. Reaberturas e transferências mantêm equipe e autor registrados em cada resolução.

- Download exclusivo para administradores ativos, inclusive por URL direta; somente GET.
- UTF-8 com BOM, ponto e vírgula e campos entre aspas para leitura no Excel. Datas incluem o deslocamento do fuso ativo do portal.
- Colunas: chamado, ciclo, título, equipe, resolvido por, status do ciclo, início, vencimento, fechamento e SLA. Não inclui descrição, solução, mensagens, notas internas ou anexos.
- Filtros e regras de SLA iguais aos indicadores. Legados sem fechamento entram somente em Todo o histórico; dados ausentes não recebem valores inventados. Uma consulta vazia gera somente o cabeçalho.
- Filtros inválidos exibem erros no formulário e HTTP 400, sem gerar download. Textos com prefixos de fórmula recebem uma tabulação dentro do campo citado, destinada à leitura no Excel; essa tabulação faz parte do dado exportado.
- A exportação usa cache privado desabilitado e não altera os registros do atendimento.

Sem migração ou nova dependência de execução. Pare o portal e os alertas, atualize para o código aprovado, execute `python scripts/validar_atualizacao.py` com o Python da venv e reinicie. Aplique migrações pendentes se estiver vindo de versões anteriores. Em produção, execute também `collectstatic --noinput`. Publicar a Release não instala a atualização nas máquinas existentes.
