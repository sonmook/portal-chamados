# Nexaltri v1.17.2

Correção da validação de backups no Windows.

O código era atualizado corretamente para v1.17.1, mas a suíte completa podia falhar com **WinError 32** ao limpar arquivos SQLite temporários. As transações dos testes não fechavam suas conexões, e o cursor de referências de anexos permanecia ativo quando a verificação rejeitava um backup incompleto.

- Conexões dos testes são fechadas após commit/rollback.
- A verificação de anexos fecha o cursor antes da conexão, inclusive ao lançar erro, liberando o arquivo para remoção da cópia parcial.
- O teste de symlink real identifica somente WinError 1314 como falta do privilégio de criação e o registra como não executado nesse ambiente. Um teste simulado continua conferindo a rejeição de links, sem exigir execução como administrador.
- A CI executa a suíte completa também no Windows a partir desta versão, em pasta com espaços. O escopo anterior permanece para revisões históricas.
- A correção do Excel da v1.17.1 continua incluída. Os critérios de backup, integridade, referências de anexos e restauração são preservados.

Sem migração ou nova dependência. Pare portal e alertas, faça backup, atualize o código aprovado, execute `python scripts/validar_atualizacao.py` com o Python da venv e reinicie após a aprovação. Não é necessário apagar banco, chamados, uploads ou recriar usuários.

[Validação e interpretação dos resultados](../validacao-atualizacoes.md).
