# Fontes da Nexaltri

Manrope em títulos; Inter na interface. Arquivos locais, sem requisições de fontes para terceiros. As licenças SIL Open Font License acompanham cada família nos arquivos `*-OFL.txt`.

Fontes originais do repositório oficial Google Fonts:

- `ofl/manrope/Manrope[wght].ttf`, blob Git `75274da58537d6123b14f2cd0c355ad4681fc2b3`.
- `ofl/inter/Inter[opsz,wght].ttf`, blob Git `047c92f6e2212473dc436020afed689527076d44`.

Arquivos WOFF variáveis derivados com FontTools, preservando nomes/licença/layout e glifos U+0020–024F, pontuação U+2000–206F, euro, marca registrada e setas esquerda/direita. Demais caracteres usam fallback do sistema. Não são famílias novas; os nomes originais permanecem. O wordmark SVG usa contornos da Manrope em peso 800, com espaçamento óptico próprio, sem depender de uma fonte instalada.

Origem: https://github.com/google/fonts/tree/main/ofl/manrope e https://github.com/google/fonts/tree/main/ofl/inter.
